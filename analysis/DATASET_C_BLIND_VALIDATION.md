## 6. Перенос Dataset A -> B -> C

Основное сравнение использует допуск +/-2 `segment_id`, как в предыдущих benchmark-отчётах.

| Engine | Dataset | Predictions | Precision | Recall | F1 |
|---|---|---:|---:|---:|---:|
| Local Peak | A | 26 | 0.577 | 0.312 | 0.405 |
| Local Peak | B | 26 | 0.615 | 0.471 | 0.533 |
| Local Peak | C | 24 | 0.583 | 0.583 | 0.583 |
| PELT | A | 63 | 0.381 | 0.500 | 0.432 |
| PELT | B | 60 | 0.350 | 0.618 | 0.447 |
| PELT | C | 63 | 0.238 | 0.625 | 0.345 |

Диагностический вывод:

- **Local Peak:** положительный перенос. Precision остаётся в устойчивом диапазоне 0.577-0.615, Recall последовательно растёт 0.312 -> 0.471 -> 0.583, F1 растёт 0.405 -> 0.533 -> 0.583. На C число predictions точно совпало с числом Gold, хотя совпадение количества само по себе не гарантирует правильных границ.
- **PELT:** переносится как high-recall comparator, но не как самостоятельный детектор. Recall устойчив и на C достигает 0.625, однако Precision падает до 0.238 из-за систематической сверхсегментации: 63 predictions против 24 Gold.
- Формальный verdict не присваивается, поскольку заранее утверждённых порогов приёмки нет.

Системный профиль Local Peak:

- Основная сила: точное количество границ и сравнительно устойчивый Precision.

- Основной источник FP: локальные примеры и детали внутри длинной темы.
- Два near-miss показывают, что часть ошибок связана с привязкой semantic peak к соседнему SRT-cue, а не с полной потерей перехода.

## 10. Итоговая диагностика

### LOCAL PEAK TRANSFER DIAGNOSIS

Положительный диагностический перенос. Local Peak показывает лучший результат на Dataset C: F1 0.583 при +/-2, с устойчивым Precision 0.583 и выросшим Recall 0.583. Число predictions соответствует целевой гранулярности Gold. Остаточный риск сосредоточен в gradual transitions, коротких организационных вставках, Q&A и нескольких сильных переходах без выраженного локального пика.

### PELT TRANSFER DIAGNOSIS

Частичный перенос в роли recall comparator. Recall 0.625 сопоставим с Dataset B, но Precision падает до 0.238. PELT находит на одну Gold-границу больше Local Peak, однако ценой 38 дополнительных FP. Главный системный дефект на C - over-segmentation: 63 predictions против 24 Gold.

### CROSS-ENGINE FINDINGS

1. Local Peak лучше соответствует целевой гранулярности и даёт F1 0.583 против 0.345 у PELT.
2. Оба метода уверенно находят технические начала окон, но хуже справляются с постепенными переходами, короткими организационными блоками и сменами режима Q&A.
3. Самые важные общие пропуски для последующего исследования: явный практический переход `1808`, близкая пара `431/433`, постепенный переход `2181` и Q&A-переход `2214`.
4. Различные наборы найденных Gold-boundary показывают взаимодополняемость сигналов, но текущий blind-run не разрешает ретроспективно строить или оценивать hybrid.
5. По данным этого blind-run нельзя подбирать новые параметры на Dataset C без превращения C в development set. Любые изменения следует проектировать по A/B или на отдельном development-наборе, а C сохранять как зафиксированный контрольный результат.
6. Формальный PASS/FAIL не назначается: acceptance thresholds до просмотра Dataset C не были определены.
