## 5. Форма одного ответа

Копировать только форму, заполнить варианты. L1–L7 — точные алиасы перечисленных link IDs; T1/T2 и F1–F3 — вопросы представления, не новые canonical IDs и не машинная заявка. Пропуски и фраза «всё остальное нормально» не интерпретируются как согласие. Для переадресации нужен существующий Topic ID; для приёма/отклонения — подтверждение просмотра полного связанного контекста, а не одного цитируемого предложения.

Пакет: Issue #68 / QA SHA-256 4b1529e5fad4fa2f259aca0b86cf9fb3f14e1a2326ee4e91a7a59b330cda996b

L2 = [...]; контекст проверен: [...]; причина: ...

L7 = [...]; контекст проверен: [...]; причина: ...

## 6. Чисто технический остаток после решений

Перед применением ответов устранить известное техническое ограничение: текущий `batch_review.py` принимает только `active` (сейчас 0), а все семь вопросов уже находятся в `deferred`; он также блокирует повторное решение для того же link ID. Прямая повторная загрузка этих семи ответов не поддержана. Требуется проверить/реализовать сохраняемый ревизионный переход от прежнего DEFER к новому явному решению, используя существующие review/revision primitives и сохраняя старую запись. Форма выше собирает решения автора; она не изображает уже работающий автоматический импорт. В этой задаче код применения не изменялся.

Далее записать только явные ответы в поддержанные review/revision records, сохранить историю, проверить соседние границы и provenance; затем выполнить принятый Canonical Knowledge admission, детерминированный Obsidian export и проверку source-navigation реального S1. Непринятые/DEFER элементы остаются видимыми и не попадают в accepted knowledge. Если ответ потребует неподдержанного смыслового выбора, это отдельная граница полномочий.

Есть Evidence четырёх видео из семи зарегистрированных источников; три документа без Canonical Evidence. Их нельзя молча считать обработанными. Полное покрытие, accepted export и завершение S1 ещё не доказаны. Известное отличие установленного runtime от PR остаётся без изменений; merge/deploy, S2/S3 Roadmap и Dataset/Gold этой формой не разрешаются.
